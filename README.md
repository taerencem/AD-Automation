# Active Directory Automation Toolkit

PowerShell-based automation tools for real-world Active Directory administration.  
Designed to demonstrate enterprise-level skills in identity management, Group Policy, security, and user lifecycle operations.

---

## 🔧 Purpose
This toolkit showcases automation skills used by System Administrators and Level 3 Helpdesk technicians, including:

- Bulk user creation and removal  
- Group membership auditing  
- Password resets and account unlocks  
- OU cleanup and reporting  
- GPO documentation  
- Login activity and security auditing  

---

## 🧰 Technologies Used
- Windows Server  
- Active Directory  
- Group Policy  
- PowerShell  
- Azure AD (future expansion)
